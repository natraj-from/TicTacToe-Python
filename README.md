# Python Tic-Tac-Toe 🎮

A clean, interactive command-line implementation of the classic Tic-Tac-Toe game built with Python. Designed with robust input validation and error handling to ensure a smooth two-player experience.

## ✨ Features
- **Two-Player Mode:** Alternating turns for Player X and Player O.
- **Smart Input Validation:** Checks if a chosen slot is a valid digit (1–9) and ensures squares cannot be overwritten.
- **Error Handling & Attempt Limits:** Gives players up to two attempts to enter a legal move before skipping their turn.
- **Dynamic Win/Draw Detection:** Automatically scans all winning combinations after every move and declares a winner or a draw.

## 🚀 How to Run
1. Make sure you have [Python](https://www.python.org/) installed on your system.
2. Clone this repository or download the `tictactoe.py` file.
3. Open your terminal or command prompt in the project folder and run:
   ```bash
   python tictactoe.py
4. Follow the on-screen prompts by entering numbers 1 through 9 corresponding to the board grid.
